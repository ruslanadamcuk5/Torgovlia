# Torgovlia Platform — универсальная SaaS-платформа для торговых точек

Документ описывает превращение текущего сайта «Рыбная лавка» в универсальную
multi-tenant платформу: магазины для владельцев торговых мест на рынке, подключаемые
сервисы (бесплатные и платные), отдельный сайт продаж и центральная панель
управления платформой.

## Два продукта в одном репозитории

| Продукт | Для кого | Что внутри |
|---|---|---|
| **Витрина арендатора** (`tenant app`) | Владелец торгового места, его продавцы и покупатели | Магазин, каталог, заказы, клиенты, дизайн, сервисы, простая админка |
| **Платформа** (`platform app`) | Владелец платформы и его команда | Сайт продаж, регистрация, оплата, домены, хостинг, деплой, мониторинг, биллинг, поддержка |

Оба продукта используют один backend и одну базу, но разные наборы маршрутов,
шаблонов и прав доступа. Это **модульный монолит**, а не набор микросервисов:
так проще запускать, дешевле сопровождать и достаточно для сотен арендаторов.

## Главные принципы

1. **Просто для арендатора.** Владелец торгового места не должен разбираться в
   хостинге, DNS и API. Он видит понятные карточки: «Доставка», «Бронирование»,
   «Рассылки» — и кнопку «Подключить».
2. **Сложность — на стороне платформы.** Домены, SSL, деплой, мониторинг,
   резервные копии и биллинг автоматизируются в центральной панели.
3. **Универсальность через пресеты.** Любая категория товаров (рыба, мясо, овощи,
   цветы, одежда, электроника, стройматериалы…) — это набор терминов, полей,
   категорий, шаблонов и включённых сервисов.
4. **Сервисы модульные.** Каждый сервис имеет код, описание, зависимости, тариф и
   состояние на каждом сайте. Полный каталог виден и арендатору, и платформе.
5. **Данные арендаторов изолированы.** Каждая бизнес-таблица содержит `tenant_id`,
   доступ проверяется на уровне API и подтверждается тестами.
6. **Провайдеры подключаемые.** hoster.by, ispmanager, платёжный провайдер, SMS,
   S3 — за едиными интерфейсами. Ручной режим — такой же адаптер, как и API.

## Как зайти

| Контур | Адрес | Логин |
|---|---|---|
| Сайт продаж | `http://localhost:5173/start` | — |
| Магазин (рыбный) | `http://rybnaya.localhost:5173` | `+375 29 111-22-33` / `ChangeMe123!` |
| Магазин «Цветы» | `http://flowers.localhost:5173` | `+375 29 111-22-66` / `ChangeMe123!` |
| Магазин «Мясо» | `http://meat.localhost:5173` | `+375 29 111-22-77` / `ChangeMe123!` |
| Платформа | `http://localhost:5173/platform/login` | `+375 29 111-00-00` / `ChangeMe123!` |

Пароли по умолчанию только для разработки: смените их в production.

Сайт продаж: `http://localhost:5173/start`. В production укажите хосты платформы
в `VITE_PLATFORM_HOSTS` (например, `torgovlia.by,www.torgovlia.by`) — на них
корень сайта открывает лендинг, а поддомены магазинов — витрины.

## Ключевые решения, которые нужно подтвердить

1. **Модель размещения:** общий multi-tenant рантайм (рекомендуется) или отдельный
   хостинг для каждого арендатора.
2. **Платёжный провайдер** для оплаты подписок арендаторами (bePaid / WebPay,
   ЕРИП, банковский счёт).
3. **Режим hoster.by:** партнёрская программа с ручным подтверждением на старте +
   адаптер автоматизации позже, либо ожидание официального API.
4. **Стартовый объём MVP:** сколько сервисов входит в первый запуск.

## Глоссарий

- **Арендатор (tenant)** — торговое место / магазин на платформе.
- **Платформа** — владелец SaaS: продаёт подписки, управляет сайтами.
- **План** — набор сервисов и квот, который оплачивает арендатор.
- **Сервис** — модуль функциональности с кодом (`delivery`, `booking`, `sms_marketing`).
- **Entitlement** — право арендатора пользоваться сервисом (включён в план, куплен,
  пробный период, отключён платформой).
- **Провижининг** — создание сайта, домена, SSL и размещения после оплаты.
- **Пресет категории** — готовый набор терминов, полей, категорий и шаблонов под
  тип товара.
