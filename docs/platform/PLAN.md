# Пошаговый план разработки

План рассчитан на поэтапную поставку: после каждой фазы есть работающий
результат, который можно показать и протестировать. Оценки — для одного опытного
full-stack разработчика; с командой из 2–3 человек сроки сжимаются примерно вдвое.

Общая оценка: **22–27 недель** до публичного запуска. MVP для пилота — **8–10
недель** (фазы 0–5 в урезанном виде + минимальные шаблоны и сервисы).

## Легенда

- `[ ]` — не начато
- `[x]` — готово
- **Приёмка** — что должно работать, чтобы фаза считалась закрытой.

## Риски и меры

| Риск | Вероятность | Влияние | Меры |
|---|---|---|---|
| hoster.by не даёт API | высокая | среднее | ручной режим, адаптеры, очередь задач |
| PD-хостинг дороже | средняя | высокое | заложить в цену, выбрать тариф заранее |
| Слишком широкий MVP | высокая | высокое | волны сервисов, запуск на 3 категориях |
| Сложный онбординг | средняя | высокое | 5 шагов, демо-данные, видео, поддержка |
| Утечка данных между tenant | низкая | критическое | тесты изоляции, RLS позже, аудит |
| Платёжный провайдер | средняя | высокое | ручной счёт как fallback |
| Нагрузка на shared-хостинге | средняя | высокое | VPS, мониторинг, лимиты |
| Нехватка времени на поддержку | высокая | среднее | база знаний, шаблоны ответов, статус-страница |

## Метрики успеха

- 10 платящих арендаторов за первый месяц после пилота;
- конверсия «регистрация → оплата» ≥ 20%;
- время до готового сайта ≤ 10 минут (subdomain) и ≤ 1 дня (свой домен);
- uptime ≥ 99.9%;
- p95 API ≤ 300 мс;
- доля обращений в поддержку ≤ 0.2 на арендатора в месяц;
- отток ≤ 5% в месяц;
- MRR и ARPU растут за счёт add-on.
