# Дизайн-шаблоны витрины

Шаблон — это набор CSS-переменных (цвета и радиусы). Он не содержит HTML,
скриптов и не меняет структуру страниц, поэтому переключение безопасно.
Выбрать шаблон можно в админке магазина: **Настройки → Дизайн**. Там же есть
живой предпросмотр: мини-витрина собирается из текущих названия, слогана,
логотипа, фото и телефона и перекрашивается при выборе карточки — без
сохранения. Контент при смене шаблона не меняется.

## Шаблон по умолчанию для категории

`fish → ocean`, `meat → forest`, `flowers → bloom`, `vegetables → fresh`,
`grocery → sun`, `bakery → latte`, `clothing/shoes/auto/services → mono`,
`electronics → ocean`, `building → mono`, `cosmetics → berry`, `pets → fresh`,
`books/furniture/handmade → latte`, `other → market`.

Сервисные категории:

`hairdresser → salon`, `beauty → salon`, `barbershop → barber`,
`massage → spa`, `fitness → pulse`, `clinic → clinic`, `dental → clinic`,
`veterinary → clinic`, `psychology → studio`, `tutoring → studio`,
`consulting → studio`, `autoservice → garage`, `repair → craft`,
`cleaning → fresh`, `photo → mono`, `events → bloom`.

Шаблон задаёт только цвета и радиусы. Структуру витрины выбирает
`business_type` арендатора (`goods`, `services`, `hybrid`), поэтому шаблоны
работают и для товаров, и для услуг — см. [`BOOKING.md`](BOOKING.md).

## Как это устроено

- Реестр: `backend/app/platform/templates.py`.
- Публичный список: `GET /api/templates` (код, название, описание, токены).
- Настройка магазина хранит `template` в JSON настроек.
- `GET /api/site` отдаёт блок `theme` с токенами; витрина накладывает их как
  CSS-переменные (`--teal`, `--ink`, `--radius` и т.д.). Если у магазина задан
  `accent_color`, акцент и производные светлые оттенки пересчитываются на
  бэкенде (`apply_accent`), поэтому предпросмотр и витрина совпадают.
- Админка и панель платформы используют собственную палитру и не меняются.

## Как добавить шаблон

1. Добавить `DesignTemplate` в `DESIGN_TEMPLATES` с полным набором токенов.
2. При необходимости указать его в `PRESET_TEMPLATE` для категории.
3. Проверить контраст текста и кнопок на светлом фоне.
4. Добавить код в тест `test_design_templates_apply_to_site`.

Миграция не нужна: шаблон хранится в JSON настроек.
